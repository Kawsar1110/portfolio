# Md. Kawsar Hasan — Portfolio

## How to use

1. **Add your photo:**
   - Put your photo file (e.g. `photo.jpg`) in this folder
   - Open `index.html`, find the comment `<!-- TO USE YOUR PHOTO -->`
   - Replace the placeholder `<div>` with: `<img src="photo.jpg" alt="Md. Kawsar Hasan">`

2. **Deploy to GitHub Pages:**
   - Upload `index.html` (and your photo) to your repo `kawsar11110.github.io`
   - Your site will be live at https://kawsar11110.github.io

## Files
- `index.html` — Complete portfolio (single file, no dependencies needed)
